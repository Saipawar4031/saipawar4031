## 👨‍💻 About Me

I'm **Sai D Pawar**, a Mechatronics Engineering student at **MMIT, Pune**, passionate about embedded systems, robotics, and intelligent automation. I enjoy building hardware that thinks, from ESP32 and STM32 based robots to autonomous drone missions simulated in Webots. I write in C, C++, and Embedded C, work with CATIA V5, SolidWorks, and MATLAB, and I'm steadily growing my interest in digital electronics and VLSI engineering.

### 🤖 ESP32 Landmine Detection Robot
`ESP32` `Embedded C` `Metal Detection Sensor` `Motor Control`

- Built an ESP32-controlled mobile robot for remote metal detection
- Integrated the metal detection sensor with motor control
- Implemented sensor-triggered alerts for remote operation

### 🛡️ Smart Intrusion Detection & Surveillance Bot
`ESP32` `Embedded C` `PIR Sensor` `Camera Module`

- Built an ESP32-based surveillance robot for motion detection and monitoring
- Integrated sensor data processing and alert logic
- Designed the system to identify unauthorized movement

### 🏎️ Technoxian RC Car
`4WD Chassis` `Brushed DC Motors` `LiPo Battery`

- Built a four-wheel-drive RC robot for the Technoxian World Robotics Championship
- Worked on drivetrain and power system integration
- Gained hands-on experience in prototyping and competition-based engineering
